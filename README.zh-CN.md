# CinnaTool

[English](./README.md) | 简体中文

将 AI 聊天、待办事项和常用文件工具放在一起的桌面工作台。随手安排任务、保存有用的文字，也能快速打开日常会用到的小工具。

## 可以做什么

- 管理待办列表，通过日历安排工作。
- 连接自己配置的 AI 服务，进行聊天和文字翻译。
- 保存剪贴板片段，阅读文件并搜索内容。
- 对比代码、查看日志、浏览图片和起草文档。

界面支持中英文切换、外观设置和快捷工具。AI 功能使用你在设置中配置的服务与凭据。

## 从源码运行

准备 Node.js 和仓库声明的 pnpm 版本，然后运行：

```sh
pnpm install --frozen-lockfile
pnpm electron:dev
```

本地开发服务启动后会打开桌面应用。需要使用 AI 功能时，在设置中配置自己的 AI 服务。
